## Forecasting Equity Market Returns Using Macroeconomic Indicators and Machine Learning Techniques

# Research Overview
This repository contains the code, datasets, outputs, figures, and supporting materials used in the research project.

# Objective
To evaluate whether macroeconomic indicators and market volatility measures can forecast future S&P 500 returns and whether machine learning models outperform traditional statistical approaches.

# Models Evaluated
- Historical Mean Baseline
- Previous Return Baseline
- Multiple Linear Regression
- Random Forest Regression
- Gradient Boosting Regression

# Predictor Variables
- InterestRate_Change_Lag3
- Inflation_YoY_Lag1
- GDP_Growth_YoY_Lag1
- Unemployment_Change_Lag1
- VIX_Change
